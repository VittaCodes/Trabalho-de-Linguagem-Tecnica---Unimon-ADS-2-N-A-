                                      ------UniMon------
Unimon é um jogo de luta pokemon, desenvolvido como projeto academico.
no jogo o jogador podera escolher um pokemon contra um adversario e participar de batalhas, ultilizando diferentes ataques e habilidades, podendo tambem capturar pokemon.

A proposta é criar uma experiencia simple, e divertida e interativa, permitindo que o jogador escolha seu pokémon e ultilize suas habilidades de ataque para vencer o oponente.

O jogo será baseado em batalhas 1x1 (um contra um) nas quais dois pokemon se enfrentam em uma arena.

Cada pokemon podera possuir caracteristicas proprias, como: 
-PONTOS DE VIDA (HP)
PODER DE ATAQUE
DEFESA
VELOCIDADE
TIPO

                                          ----Dinamica do jogo----

a Partida começa com a seleção de pokemon dos jogadores, após isso a partida é iniciada.

durante a luta, os pokemons poderao realizar diferentes açoes, como atacar ou ultilizar habilidades proprias e/ou especiais.

O jogador deverá escolher suas acoes de acordo com as caracteristicas do seu pokemon e do adversario, tornando o combate mais estrategico

o OBJETIVO PRINCIPAL é derrotar o pokemon adversario, reduzindo seu hp até chegar a zero.

                                        ---Objetivo do projeto---

O principal objetivo do UniMon é desenvolver um jogo de luta simples que permita aplicar, de forma prática, o conhecimentos de programação aprendido na materia de Linguagens Tecnicas do nosso professor preferido <3

                                       ---Principais sistemas---

O projeto contara com diferentes sistemas responsaveis pelo funcionamento do jogo:

sistema de seleção que permite escolher o pokemon que sera ultilizado na batalha

sistema de batalha que controla as acoes dos jogadores

sistema de ataques que determina os ataques disponiveis para cada pokemon

sistema de dano que calcula o dano causado pelos ataques

sistema de hp que controla a vida dos pokemon

sistema de defesa que influencia a quantidade de dano recebido

sistema de vitoria e derrota que determina o resultado de batalha

sistema de habilidades que permite ultilizar ataques ehabilidades especiais 

sistema de interface que apresenta informacoes da batalha de forma cala para o jogador


                                      ----condicao de vitoria----

A batalha termina quando um dos pokemon fica sem pontos de vida. o jogador que conseguir reduzir o hp do pokemon adversario a 0 sera declarado vencedor
